# 🎯 AI Interview Mentor

An AI-powered interview preparation platform that generates role-specific technical interview questions, expert answers, and personalized improvement suggestions.

## Features

* Role-based Interview Preparation
* Multiple Experience Levels
* AI-Generated Technical Questions
* Expert-Level Answers
* Personalized Improvement Tips
* Structured Output using Pydantic
* Interactive Streamlit Interface

## Tech Stack

* Python
* Streamlit
* LangChain
* OpenRouter
* Pydantic
* Prompt Engineering

## Supported Roles

* Generative AI Engineer
* AI Engineer
* Machine Learning Engineer
* Python Developer
* Data Scientist

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/AI-Interview-Mentor.git

cd AI-Interview-Mentor

pip install -r requirements.txt
```

## Environment Variables

Create a `.env` file:

```env
OPENROUTER_API_KEY=your_api_key_here
```

## Run Application

```bash
streamlit run app.py
```

## Architecture

User Input
↓
Streamlit UI
↓
LangChain Prompt
↓
OpenRouter LLM
↓
Pydantic Parser
↓
Interview Question
Expert Answer
Improvement Tips
